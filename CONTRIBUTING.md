# Contributing

## Set up

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
```

GUI tests need a display. On a server use Xvfb: `Xvfb :97 &` then `DISPLAY=:97 python dev/guitest43.py`.

## Tests

Scripts in `dev/` print `ok` / `FAIL` lines and exit non-zero on failure. **`python dev/run_all.py`** runs all of them and prints one table (`--fast` = no window, `--window` = window tests only; on a server use `xvfb-run -a python dev/run_all.py`).

## Adding things

- **A part:** a file in `src/vibesimulation/workspaces/logisim/components/<library>/`, subclass `Component`, decorate with `@register`, list it in `workspaces/logisim/circuit/parts_folders.py`.
- **A setting:** copy a folder in `src/vibesimulation/workspaces/settings/<category>/` (its `__init__.py` has `item(page)`), then add `"<category>.<name>"` to `ORDER` in `workspaces/settings/registry.py`.
- **An example:** one `add(...)` call in `product/examples.py` (or `examples_sv.py`); `dev/exampletest.py` checks that it compiles and runs.
- **A SystemVerilog feature:** one new file in `src/vibesimulation/workspaces/systemverilog/core/features/`: subclass `Feature`, set `name`, `order` and `triggers`, write `apply(ctx)`, decorate with `@feature`, and add its name to `FALLBACK` in `features/__init__.py`. Keep every token on its original line (use `TokenEditor`). Add a case to `dev/svtest.py`: compare against `iverilog -g2012` with `diff(...)` when iverilog supports the construct.
- Design patterns used, and where, are listed in `docs/MANUAL.md`. Keep one feature or one box per file.
